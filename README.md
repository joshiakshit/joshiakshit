## Featured Projects

### [Axis](https://github.com/joshiakshit/axis)

An offline-friendly Android client for Galgotias University students.

It provides attendance tracking, forecasting, timetables, QR check-in, academic planning, and remote app management.

`Kotlin` `Jetpack Compose` `Hilt` `Room` `Retrofit` `Cloudflare Workers`

### [CryptScan](https://github.com/joshiakshit/crypto-decompiler)

A Python CLI for detecting cryptographic misuse in Android APKs.

It performs static analysis for hardcoded keys, weak algorithms, insecure TLS, broken certificate validation, and other security problems.

`Python` `Androguard` `Static Analysis` `Jinja2` `Pytest`

### [E-WAVE](https://github.com/joshiakshit/electronic-warfare)

An adaptive electronic support scan scheduler based on online machine learning.

It uses multi-armed bandits, Bayesian state tracking, and periodic-signal prediction to decide which frequency bands to scan.

`Python` `FastAPI` `TypeScript` `Online Learning` `Bayesian Models`

### [Table Stakes](https://github.com/joshiakshit/poker)

A shared poker chip tracker for physical Texas Hold'em and Teen Patti games.

It manages player sessions, bets, turns, side pots, hand history, and table state across multiple phones.

`Node.js` `SQLite` `JavaScript` `Docker` `PWA`
